# 时间行为（真实照片 + 慢速运动）

单帧批测回答「这一帧判得对不对」，这张表回答「连续播的时候稳不稳」：
ffmpeg 的 `zoompan` 把一张真实壁纸推成 60 帧（30 fps，2 秒慢推），
用 `tools/hdr_seq` 跑整段——它内部调用 `nvn_hdr_hist.inc` 用的同一条
`s2a_hdr_auto_l1b_step_fused`，所以量到的就是上屏会发生的过渡。

判据与理由：

| 指标 | 上限 | 理由 |
|---|---|---|
| 单帧 `knee_lo` 相对变化 | 2% | 平滑的时间常数（60 Hz 每帧 10%）应吸收掉内容微动 |
| 慢速运动的最大场景权重 | 0.05 | 平移不是切镜，误判会让画面「先暗后亮」 |
| 方向翻转次数 | 2 | 允许数值抖动，不允许来回呼吸 |

| 片 | 帧数 | knee_lo 起→止 | 单帧最大变化 | 最大场景权重 | 方向翻转 | 纸白增益（稳态） | 0.50 增益 | 0.832 增益 | 空帧 |
